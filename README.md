## Структура репозиторію

- [lab2](./lab2) — **Лабораторна робота №2** (Варіант 10)
  - **AppBar:** «Пошук авто»
  - **Body:** `Center` → `ElevatedButton("Переглянути")`
  - **BottomNavigationBar:** два пункти відповідно до теми («Авто» / іконка авто)

- [lab3](./lab3) — **Лабораторна робота №3** (Група 3: Cards-first layout)
  - **Тема:** «Пошук авто: Audi A6 Sedan»
  - **Макет:** кнопки — зверху (`Row`), заголовок — під кнопками (`Text`), опис — у центральній частині (`Expanded` + `Spacer`), зображення — внизу екрана (`Container`).
  - **Використані layout-віджети:** `Column`, `Row`, `Container`, `Padding`, `Expanded`, `Spacer`.

- [lab4](./lab4) — **Лабораторна робота №4** (Власні віджети та декомпозиція інтерфейсу)
  - **Тема:** «Пошук авто: Audi A6 Sedan» (Група 3)
  - **Структура папок:** `screens/` (екран `lab4_screen.dart`) та `widgets/` (власні компоненти `StatelessWidget`).
  - **Виділені компоненти:**
    - `ActionButtonsWidget` — блок кнопок дії зверху;
    - `HeaderWidget` — заголовок та категорія запису;
    - `InfoCardWidget` — інформаційний блок опису;
    - `ImageBlockWidget` — блок із зображенням та заглушкою.

- [lab5](./lab5) — **Лабораторна робота №5** (StatefulWidget та управління станом)
  - **Тема:** «Пошук авто: Audi A6 Sedan»
  - **Клас екрана:** `Lab5Screen` (`StatefulWidget`) та клас стану `_Lab5ScreenState`.
  - **Змінні стану (оновлення через `setState()`):**
    - `bool _isFavorite` — стан іконки «обране»;
    - `bool _showExtraDetails` — стан `Switch` (показ додаткових характеристик, зміна стилю та бейдж);
    - `int _actionCounter` — лічильник натискань кнопки дії;
    - `String _userNote` — текст із `TextField` через `onChanged`.

- [lab6](./lab6) — **Лабораторна робота №6** (Списки та моделі даних)
  - **Тема:** «Пошук авто (Каталог)»
  - **Модель даних:** клас `CarModel` у `models/car_model.dart` з полями `int id`, `String title`, `bool isFavorite`, `CarStatus status` (`enum`).
  - **Колекція:** `List<CarModel>` (початково 5 автомобілів).
  - **Інтерфейс:** `ListView.builder` та `ListTile`.
  - **Функціонал:**
    - Додавання нового авто через діалог (`FloatingActionButton`);
    - Видалення авто кнопкою у списку;
    - Зміна стану `isFavorite` (іконка ⭐ / зірочка);
    - Зміна статусу авто (`CarStatus` по колу: В наявності ⇄ Заброньовано ⇄ Продано);
    - Статистика `Map<String, int>` (всього, обрані, в наявності, бронь) з відображенням на екрані.

- [lab7](./lab7) — **Лабораторна робота №7** (Робота з файлами JSON та збереження даних)
  - **JSON-файл:** `assets/cars.json` з 5 початковими автомобілями (`id`, `title`, `isFavorite`, `status`).
  - **Конфігурація:** зареєстровано `assets/cars.json` у `pubspec.yaml`.
  - **Модель даних:** `CarModel` з методами `fromJson()` та `toJson()`.
  - **Сервіс збереження:** `CarStorageService` для зчитування з assets та збереження змін у локальний JSON-файл.
  - **Інтерфейс:** `ListView.builder` та `ListTile`.
  - **CRUD операції:** додавання нового елемента, редагування назви/статусу, видалення елемента, перемикання обраного (`isFavorite`).

- [lab8](./lab8) — **Лабораторна робота №8** (Форми, валідація та навігація)
  - **Екрани:** `RegisterScreen` (початковий екран реєстрації) та `HomeScreen` (головний екран вітання).
  - **Форма:** `Form` з `GlobalKey<FormState>`.
  - **Поля введення (`TextFormField`):**
    1. Ім’я користувача (мінімум 3 символи);
    2. Дата народження (валідація дати + вибір через `DatePicker`);
    3. Email (перевірка на `@` та домен);
    4. Пароль (мінімум 6 символів, перемикач видимості);
    5. Підтвердження пароля (збіг із паролем).
  - **Контролери:** `TextEditingController` для всіх полів.
  - **Кнопка «Зареєструватися»:** запуск повної валідації форми.
  - **Навігація:** `Navigator.push()` на `HomeScreen` **виключно після успішної валідації**, передача імені користувача та відображення тексту `«Вітаємо, $userName!»`.

- [lab9](./lab9) — **Лабораторна робота №9** (Теми, власні шрифти, AppColors, AppStyles та ProfileScreen)
  - **Теми (Light / Dark mode):** динамічне перемикання теми через `ThemeMode.light` та `ThemeMode.dark` із налаштованими `AppTheme.lightTheme` та `AppTheme.darkTheme`.
  - **Перемикач теми:** інтерактивний `SwitchListTile` на екрані та швидка кнопка в `AppBar`.
  - **Власний шрифт:** підключено шрифт `AppFont` (`AppFont-Regular.ttf`, `AppFont-Bold.ttf`) через `pubspec.yaml`, що використовується в усьому додатку.
  - **Графічні ресурси:** аватар користувача (`assets/images/avatar.png`) та декоративний банер (`assets/images/header_bg.png`).
  - **Іконки:** власна PNG-іконка бейджа (`assets/icons/custom_badge.png`) та стандартні Material Icons для навігації й налаштувань.
  - **Власна палітра (`AppColors`):** `primary`, `secondary`, `accent`, кольори фону (`backgroundLight` / `backgroundDark`, `surfaceLight` / `surfaceDark`), тексту та рамок, які замінюють стандартні кольори Flutter.
  - **Типографіка (`AppStyles`):** стилі заголовків (`titleLarge`, `titleMedium`, `titleSmall`), підзаголовків (`subtitle`), основного тексту (`bodyLarge`, `bodyMedium`), кнопок (`button`) та константи узгоджених відступів і радіусів.
  - **Екран `ProfileScreen`:**
    - Аватар, ім’я (`Юрій Лепак`), статус та бейдж ролі;
    - Перемикач світлої/темної теми;
    - Контактна інформація (email, телефон, місто);
    - Розділ налаштувань, сповіщень та безпеки;
    - Кнопка виходу з акаунта з модальним діалогом підтвердження.
